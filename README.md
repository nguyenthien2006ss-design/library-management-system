# LibHub - Quản lý thư viện (ASP.NET Core MVC)

## Chạy bằng Visual Studio 2022 (17.8+)
1. Cài .NET 8 SDK và workload "ASP.NET and web development".
2. Mở LibraryManagement.csproj, nhấn F5. Trình duyệt mở tại http://localhost:5080.

Lưu ý: nếu đã chạy phiên bản trước, XÓA file library.db rồi chạy lại để tạo cấu trúc dữ liệu mới.
